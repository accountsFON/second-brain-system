# GEMINI.md

You are working in the source repository for the Second Brain System. This repository publishes a generic vault builder, operator guide, and starter templates. It is not itself a generated organization vault.

Read [AGENTS.md](./AGENTS.md) first. It is the shared contributor entrypoint for Codex, Gemini, Copilot, Cursor, and other repository agents.

Generated vaults still use a root `CLAUDE.md` as their tool neutral brain. That file is created by [second-brain-initiate.md](./second-brain-initiate.md).
